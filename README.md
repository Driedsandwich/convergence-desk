# Convergence Desk

An autonomous research agent that watches a user-selected set of public market voices, detects when trusted voices converge on the same token narrative, checks that narrative against live market evidence, and records the practice position it would take (entry, size and exit as one decision) inside user-defined risk limits — or the reasons it declined.

Practice trades only. No real funds are moved.

Work in progress for BLI Legal Tech Hackathon 2 (DoraHacks).
